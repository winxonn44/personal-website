Selected work

VoroNav: offline navigation for autonomous systems (2026, flagship)

Camera → SAM 2 floor mask → bird’s-eye grid → maximum-clearance Voronoi roadmap, fully on-device. The Voronoi engine (Jump Flooding) is written from scratch in NumPy, multithreaded Numba and a fused Metal GPU kernel, all bit-identical to an exact oracle.

  • Fused Metal kernel: a 2048² Voronoi diagram in 14 ms, 276× faster than NumPy and 100× faster than eager PyTorch.
  • Benchmarked against A*, clearance-weighted A* and RRT* on 94 maps (58K planner runs): ≤0.1% collisions vs 0.6–1.1% for A*; ties tuned weighted A* on safety with 1.5–3.6× faster queries.
  • Fault-injection study (190K graded plans): a leak-detection gate raised recall from 8% to 65%.

Python, PyTorch MPS, Metal, Numba, SAM 2, pytest (358 tests). Code and results

VoroLens: segmentation-driven Voronoi mosaics in the browser (2026–now)

Lead developer, UCLA Math + Code + Art. An interactive app for the Algorithmic Forms exhibition at the Oceanside Museum of Art (August 2027). Click any object and SlimSAM segments it, then mosaics only that object. SlimSAM runs entirely client-side in a Web Worker on WebGPU with a WASM fallback; images never leave the visitor’s device. Author of Chapter 2 of the lab’s open textbook, Voronoi Tessellation and Adaptive Sampling. A live version runs on this site.
